# Project-exam-2 - Holidaze

Holidaze is a venue booking platform developed as our final exam. The project allows customers to browse and book venues, while venue managers can create, update, and manage their own listings through a dedicated management interface.


## Built With

- React
- Styled components

### Installing


1. Clone the repo:

```bash
git clone https://github.com/OJOverby/project-exam-2.git
```

2. Install the dependencies:

```
npm i

```

3. Build the site

```
npm run build
```
### Running

To run the app, run the following commands:

```bash
npm run start
```

To run tests on the site, rim tje following commands:


```bash
npm run test
```
